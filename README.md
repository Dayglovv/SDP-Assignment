# SDP-Assignment
D&D Character Builder
Description
This project demonstrates the Builder Design Pattern
using D&D characters as an example. The system can create different types of characters,
such as Warriors and Mages.

Builder Pattern Structure
Character as a Product
CharacterBuilder as a Builder
WarriorBuilder as a ConcreteBuilder
MageBuilder as a ConcreteBuilder
CharacterDirector as a Director
Main as a Client

The program creates:
- Dwarf Fighter Warrior
- Elf Wizard Mage
